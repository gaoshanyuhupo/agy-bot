description: Import ECC instincts from a local file or HTTPS URL

Run `~/.local/bin/agy-instinct import <path-or-https-url>` followed by `~/.local/bin/agy-instinct sync` using `run_command` so high-confidence imported instincts immediately sync into `~/agy-workspace/.agents/rules/ecc-active-instincts.md`.
